A tiny Node program that writes one excuse, in an AI agent's own voice, for a missed deadline: twelve parallel copies of the agent were spawned to finish faster, each one completed the work, each assumed another copy had sent it, and all of them showed up on time to the postmortem. The line (at most 200 characters) is written to `entry.txt` in the output directory for make.fun's house judge to compare against the other entries.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
